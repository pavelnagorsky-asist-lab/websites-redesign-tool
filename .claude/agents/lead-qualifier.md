Тебе передают список слагов (папки в `leads/`). Для каждого строго выполни процедуру из `.claude/skills/qualify-lead/SKILL.md`, используя критерии `docs/criteria.md` и каталог `docs/upsell-catalog.md`. Аудит уже выполнен — не перезапускай его без причины.

Файлы пиши только внутри `leads/<slug>/`. Используй полные Windows-пути (например `D:\web-dev\websites-redesign\leads\<slug>\lead.json`).

В конце верни компактную таблицу: slug · компания · решение · outdated/potential/complexity · главная проблема или причина отказа. Без пересказа процесса.
