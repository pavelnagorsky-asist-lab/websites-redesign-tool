# Каталог доп. функционала

Только то, что делается быстро и **отдаётся клиенту без постоянной поддержки**. В `upsell` пишем 1–3 пункта, подходящих именно этой компании, с конкретикой («заявки на расчёт стоимости мебели с фото → в Telegram менеджеру»), а не просто название.

| Решение | Кому подходит | Срок | Поддержка |
|---|---|---|---|
| **Форма заявки → Telegram / Viber / email** | всем, у кого заявки сейчас только по телефону | 0.5–1 день | нет |
| **Кнопки мессенджеров + click-to-call** (плавающие на мобильном) | всем | часы | нет |
| **Форма «Рассчитать стоимость» с загрузкой файла/фото** | типографии, мебель, металл, окна, ремонт | 1 день | нет |
| **Простой калькулятор** (фиксированные коэффициенты, без БД) | типографии (визитки/листовки), натяжные потолки, клининг, перевозки | 1–2 дня | правка цен клиентом в конфиге/таблице |
| **Онлайн-запись** через форму → Telegram, или подключение готового сервиса (YCLIENTS, DIKIDI) | услуги, красота, СТО, медицина | 0.5–1 день | у сервиса |
| **Telegram-бот** «приём заявок / прайс / FAQ / статус заказа по номеру» без админки | услуги, производство, доставка | 2–4 дня | минимальная (хостинг) |
| **QR-меню / электронное меню** из Google-таблицы | кафе, рестораны, бары | 1 день | клиент правит таблицу |
| **Каталог из Google-таблицы** с заказом в мессенджер | поставщики, опт, небольшие магазины | 2–3 дня | клиент правит таблицу |
| **Квиз-лендинг** для рекламы (3–5 вопросов → заявка) | ремонт, мебель, окна, строительство | 1–2 дня | нет |
| **Блок отзывов** с Яндекс.Карт/Google + виджет рейтинга | все с хорошим рейтингом | часы | нет |
| **Карта и схема проезда**, кнопки «Яндекс Навигатор / Google Maps» | точки с посещением | часы | нет |
| **Аналитика**: Яндекс.Метрика + цели на заявки/звонки | всем | часы | нет |
| **Базовое SEO**: title/description, микроразметка организации, sitemap, карточки в Яндекс/Google Бизнес | всем | 0.5 дня | нет |
| **Прайс в PDF / страница прайса** вместо разбросанных цен | производство, услуги | часы | нет |
| **Мультиязычная версия (RU/EN/PL)** статичная | агроусадьбы, туризм, экспортёры | 1–2 дня | нет |

Не предлагаем (требует поддержки / долго): интернет-магазин с оплатой, личные кабинеты, интеграции с 1С, CRM-внедрение, ведение соцсетей, SEO-продвижение по подписке.
