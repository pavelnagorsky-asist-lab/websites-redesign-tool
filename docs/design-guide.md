# Гайд по дизайну концептов в Google Stitch

Задача концепта — за 5 секунд показать владельцу: «это мой бизнес, мои тексты и телефоны, только выглядит дорого и удобно на телефоне». Не идеал, а убедительный «до/после».

## Что генерируем

1. **Главная, DESKTOP** — обязательно.
2. **Главная, MOBILE** — обязательно (мобильная версия — главный аргумент продажи).
Ровно 2 генерации на лид, других экранов в проекте нет (ссылку смотрит клиент). Доп. функционал (форма записи, расчёт стоимости, Telegram-кнопки) — блоком на главной. Правки — локально в HTML (`docs/workflows/stitch-design.md`).

## Контент — только реальный

Берём из `leads/<slug>/audit/content.json` и скриншотов:
- точное название компании, слоган (если есть);
- реальные услуги/продукцию (названия разделов из меню и заголовков), реальные цены «от …», если есть;
- преимущества — из текстов «О компании» (годы работы, собственное производство, сроки, гарантия), переформулированные коротко;
- телефоны, адрес, часы работы, мессенджеры;
- город и область работы.

Никакого lorem ipsum и выдуманных фактов (выдуманные цифры вроде «500+ клиентов» — только если есть на сайте). Тексты — на русском.

## Структура главной (адаптировать под нишу)

1. Шапка: логотип/название, 4–6 пунктов меню, телефон, кнопка CTA.
2. **Первый экран**: что делаем + для кого + где (H1 с конкретикой: «Мебель на заказ в Гомеле от 14 дней»), подзаголовок с УТП, 2 кнопки (основная заявка + звонок/мессенджер), фото/визуал.
3. Услуги/продукция — карточки с иконкой/фото и «от N руб.».
4. Преимущества / цифры (только реальные).
5. Как мы работаем — 3–5 шагов (особенно для производства и услуг).
6. Портфолио / фото работ / меню.
7. Отзывы (если есть на картах) — можно блоком с рейтингом.
8. Форма заявки (демонстрирует доп. функционал: «заявка придёт менеджеру в Telegram»).
9. Контакты: адрес, карта-заглушка, часы, все мессенджеры.
10. Подвал с актуальным © годом.

На мобильном: бургер-меню, крупный H1, CTA в первом экране, **закреплённая нижняя панель «Позвонить / Telegram / Viber»**, карточки в одну колонку.

## Стилевые направления по нишам

Выбирать одно, не повторять одно и то же направление у лидов одной ниши подряд (смотреть `design.style` у существующих лидов).

| Ниша | Направления |
|---|---|
| Производство, металл, B2B, опт | «Industrial clean» — графит + акцент (оранжевый/жёлтый сигнальный), строгая сетка, крупные фото цеха; «Engineering blue» — тёмно-синий, белый, чертёжные линии |
| Типографии, реклама | «Bold print» — яркие CMYK-акценты на белом, крупная типографика; «Paper craft» — тёплые бумажные тона, тактильные фото продукции |
| Кафе, рестораны, кейтеринг | «Warm editorial» — кремовый фон, сериф в заголовках, крупные фото блюд; «Dark moody» — тёмный фон, тёплый свет |
| Агроусадьбы, отдых | «Nature calm» — зелень/дерево/лён, много воздуха, фото природы, сериф; |
| Услуги (ремонт, СТО, клининг, перевозки) | «Trust & action» — чистый белый, один насыщенный акцент, иконки, цены сразу, много CTA |
| Медицина, красота | «Soft premium» — светлые нейтральные, мягкие скругления, спокойный акцент |
| Обучение, детские центры | «Friendly bright» — светлый фон, 2–3 дружелюбных цвета, скругления, иллюстрации |

Цвета: отталкиваться от фирменных цветов логотипа (видно на `audit/desktop.jpg`), но осовременить (приглушить кислотность, добавить нейтральные).
Шрифты с кириллицей: Manrope, Inter, Golos Text, Onest, Geologica, Montserrat (заголовки), Unbounded (акцентные заголовки), Playfair Display / Lora (сериф для HoReCa/отдыха).

## Избегать (выдаёт «AI-шаблон»)

- фиолетовые градиенты и glassmorphism «по умолчанию»;
- «Добро пожаловать на наш сайт», «Мы — команда профессионалов»;
- английские тексты, американские телефоны, $ вместо руб.;
- стоковые люди-в-офисе для производства (лучше цех/продукция);
- 10 одинаковых карточек с эмодзи.

## Шаблон промпта для Stitch

Сохранять в `leads/<slug>/stitch-prompt.md`. Писать промпт на английском (Stitch лучше понимает), **весь видимый контент — на русском**, в кавычках.

```
Landing page (homepage) redesign for "<Company>", <industry> in <city>, Belarus.
Audience: <B2B buyers / local residents / tourists ...>. Goal: get leads (calls, messenger, request form).

Visual style: <direction name> — <palette: hex colors>, fonts: <heading font> for headings, <body font> for body text.
Mood: <2–3 adjectives>. Modern, clean, generous whitespace, rounded <N>px corners. Real photography style: <what>.

All visible text must be in Russian, use exactly this content:

Header: logo "<Company>", menu: "<item>", "<item>", ..., phone "<+375 ...>", button "<CTA>".
Hero: H1 "<...>", subtitle "<...>", buttons "<primary>" and "<secondary>", image: <description>.
Section "<Услуги>": cards — "<name> — от <price> руб.", ...
Section "<Почему мы>": "<fact>", "<fact>", ...
Section "<Как мы работаем>": 1. "<...>" 2. "<...>" ...
Section "<Наши работы>": gallery of <...>.
Section "Оставить заявку": form fields "Имя", "Телефон", "<specific field>", button "<...>", note "Ответим в Telegram в течение 15 минут".
Contacts: address "<...>", hours "<...>", phones, Telegram, Viber, map placeholder.
Footer: "© <year> <Company>".
```

Для мобильного экрана — тот же контент и стиль, плюс: `Mobile layout: hamburger menu, single column cards, sticky bottom bar with "Позвонить", "Telegram", "Viber" buttons.`

## Самопроверка перед сдачей

Скачать превью экранов и посмотреть глазами:
- первый экран за 5 секунд отвечает «что, где, как заказать»;
- весь текст на русском, нет выдуманных фактов, телефоны правильные;
- мобильная версия читается, CTA видны;
- выглядит заметно лучше текущего сайта (сравнить с `audit/desktop.jpg`, `audit/mobile.jpg`).
Если нет — править `design/*.html` и `stitch.ts push` (без генераций). Заново (`design --redo`) — только если концепт не годится целиком.
